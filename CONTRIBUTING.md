# Contributing

This project is not open for general contributions. The source code
is available for inspection, use, modification, and forking under the
**Apache 2.0 license**, but development and maintenance are handled
exclusively by the project author.

An exception is made for **ECOSYSTEM.md**. Pull requests adding or
updating projects in the ecosystem list are welcome.

For ecosystem contributions:

- The project must support S3-compatible object storage.
- Include the project name, repository URL, and a short description.
- Place the project in the appropriate category.
- Avoid duplicate entries.
- Update the category project count in the table of contents.

Bug reports, feedback, and feature suggestions are welcome through
GitHub Issues. Thank you for understanding.
